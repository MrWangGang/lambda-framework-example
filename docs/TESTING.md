## 正式业务接口的 22 项检查

1. 远程 Nacos 配置加载与 MongoDB rs0 连接。
2. Nacos 注册实际应用端口。
3. 运行中动态刷新 greeting。
4. 创建及查询商品，保留金额精度。
5. 非法商品入参返回 400。
6. 分类复合游标分页，无重复商品。
7. 带版本更新成功，旧版本返回 409。
8. 收藏唯一约束、幂等添加及删除。
9. 订单与扣库存同事务提交。
10. 请求号幂等，不重复扣库存；参数变化返回 409。
11. 库存不足返回 409，不改变库存。
12. 失败事务不留下订单，同一请求号可在条件满足后成功。
13. 两个并发事务保持库存一致。
14. 并发相同请求号只创建一单、只扣一次库存。
15. 并发购买有限库存时不超卖。
16. Redis 写入、读取、删除。
17. Redis TTL 到期。
18. 延迟消息发布确认、到期消费、Mongo 回执及 ACK；设置 2 秒，本次观察约 2.50 秒。
19. 重复投递保留原始幂等回执。
20. 无效消息进入死信队列并清理。
21. Qdrant 向量写入及最近邻查询。
22. 非法 UUID、向量维度、全零向量返回 400。

延迟观察值包含网络与轮询时间；两个并发请求的检查用于验证一致性，不是吞吐或压力测试。
